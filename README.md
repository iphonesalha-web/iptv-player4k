# IPTV Player 4K MVP

مشروع Android Studio جاهز لتطبيق IPTV MVP على Android TV.

## الميزات الحالية
- إضافة Playlist عبر M3U URL
- تحميل وتحليل القنوات من ملف M3U
- حفظ البيانات محليًا باستخدام Room
- عرض القنوات في قائمة
- تشغيل القنوات عبر Media3 ExoPlayer
- إضافة/إزالة قناة من المفضلة
- شاشة مفضلة بسيطة
- شاشة إعدادات أساسية

## التشغيل
1. افتح المشروع في Android Studio.
2. انسخ `local.properties.example` إلى `local.properties` وحدد `sdk.dir` الصحيح.
3. انتظر مزامنة Gradle.
4. شغّل التطبيق على Android TV أو Emulator.

## ملاحظات
- هذه نسخة MVP أولية قابلة للتطوير.
- لا تتضمن بعد: Xtream, EPG, Movies, Series, Catch-up.
